# Jake Van Clief

Creator of the [[Interpreted Context Methodology]] (ICM). GitHub: RinDig. Author of the academic paper "Model Workspace Protocol: Folder Structure as Agent Architecture" (arXiv:2603.16021, 2026).

## Background

Developed ICM from a content production system ([Content-Agent-Routing-Promptbase](https://github.com/RinDig/Content-Agent-Routing-Promptbase)) that applies Unix pipe-and-filter principles to AI context windows. ICM is the general-purpose extraction of those structural patterns, applicable to any repeatable multi-step workflow.

## Works

- [[Interpreted Context Methodology]] (github.com/RinDig/Interpreted-Context-Methdology) — 520 stars
- Content-Agent-Routing-Promptbase — predecessor content production system (scripting, animation specs, Remotion builds, brand management)
- Model Workspace Protocol (arXiv:2603.16021) — academic treatment of ICM

## Design Philosophy

"The filesystem is doing the work that a framework would otherwise do in code." Applies Unix principles (programs that do one thing, plain text as interface, pipe-and-filter) to AI agent orchestration.
