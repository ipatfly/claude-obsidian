# Claude Desktop

Claude Desktop is Anthropic's official desktop application wrapper for the Claude model. It provides a native, highly integrated visual chat environment for daily tasks.

## Thinking Partner Integration

Within the [[Interpreted Context Methodology|Interpreted Context Methodology (ICM)]], Claude Desktop functions as a "Thinking Partner" for conceptual analysis and research:
1. **Context Scoping**: By creating a project inside the desktop app, you can upload key reference files (`CLAUDE.md`, `CONTEXT.md`) as Project Knowledge.
2. **Interactive Steering**: Enables real-time human feedback and steering pauses, making it an excellent playground for designing systems before executing builds via [[Claude Code]].
